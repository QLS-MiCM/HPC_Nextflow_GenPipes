# RNA-seq bootcamp - Day5: HPC and Pre-Built GenPipes/Nextflow Pipelines

## Overview
Participants will be introduced to high-performance computing (HPC) infrastructure. Additionally, they will become familiar with scientific workflow systems (SWSs), including Nextflow and GenPipes, as well as their RNA-seq pipelines and input files.

## Outline
- High performance computing (HPC)
- Digital Research Alliance of Canada (Compute Canada)
- Nextflow
- Genpipes
- Hands-on
